
# Calibration guide for ply-js

This document explains how to create and apply per-scanner calibrations so that
mass and height estimates from scanned `.ply` files better match ground-truth
measurements produced by a known scanner.

## Files and scripts added

- `src/calibration.ts` / `dist/calibration.js`
  - `calibrateSamples(samples, lib)` — compute per-machine average scale and density
  - `saveCalibrationFile(id, data)` / `loadCalibrationFile(id)` — persist/load JSON calibrations
- Examples
  - `examples/calibrate.ts` — minimal example that reads labeled PLYs and writes a calibration JSON to `./calibrations`
  - `examples/apply-calibration.ts` — loads a saved calibration and applies scale+density to a single sample
- npm scripts
  - `pnpm calibrate` — run `examples/calibrate.ts` (edit the example to include your labeled samples)
  - `pnpm apply:calibration` — run `examples/apply-calibration.ts`

## Quick start

1. Provide labeled scans

Prepare a small list of labeled scans (one or more) with the ground-truth
height (in meters) and body mass (kg), and associate a `machine` id string to
group scans from the same scanner model.

The `examples/calibrate.ts` includes a small inline sample array:

```ts
const samples = [
  { file: path.resolve(__dirname, '..', 'samples', 'man.ply'), height: 1.68, mass: 75, machine: 'scanner-A' }
];
```

Replace or extend that array with your labeled files.

2. Run calibration

Using pnpm (or npm):

```bash
pnpm calibrate
```

This will:

1. read each labeled `.ply`
1. compute measured height and geometric volume
1. compute per-sample scale = (trueHeight / measuredHeight)
1. compute inferred density = mass / (geomVol * scale^3)
1. average per-machine scale and density and save a JSON to `./calibrations/<machine>.json`

3. Apply calibration

Use `examples/apply-calibration.ts` or the exported API to load the calibration
and apply it when estimating mass via `estimateMass`.

### Programmatic usage example

```ts
const lib = require('ply-js'); // or require the local src build
const cal = require('./calibrations/scanner-A.json');
const res = lib.estimateMass(points, faces, { objectType: 'avatar', bmi: 23, calibration: cal });
```

### CLI examples

```bash
pnpm calibrate
pnpm apply:calibration
```

## Notes and caveats

- Calibration accuracy scales with the number and variety of labeled samples.
  Use multiple subjects in natural poses to average scanner biases.
- The calibration assumes a uniform scale factor (isotropic scaling) and a
  single effective density per machine. If your scanner introduces non-uniform
  distortion, calibration may be insufficient; consider collecting more
  labeled samples or implementing a more advanced per-axis or per-region
  calibration.
- The code includes multiple geometric estimators (robust orientation, voxel
  estimation, and slicing). Calibration currently uses the geometric volume
  computed from faces or a voxel fallback.
